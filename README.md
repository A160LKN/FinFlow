# FinFlow

[![CI](https://github.com/A160LKN/FinFlow/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/A160LKN/FinFlow/actions/workflows/ci.yml)

Учёт личных финансов на чистом JavaScript — без фреймворков и библиотек. Работает без интернета и устанавливается как приложение.

**Демо:** https://a160lkn.github.io/FinFlow/ — нажмите «Заполнить примером», чтобы сразу увидеть приложение с данными за полгода.

## Возможности

- **Операции:** доходы и расходы по категориям, с датой и комментарием; добавление, редактирование, удаление с возможностью вернуть.
- **Итоги месяца:** доходы, расходы, остаток и сравнение расходов с прошлым месяцем — за те же дни, если месяц ещё идёт.
- **Кольцевая диаграмма** расходов по категориям: клик по сектору показывает операции только этой категории.
- **Бюджеты:** лимиты по категориям с прогрессом и предупреждением от 80 % и при перерасходе.
- **График за 6 месяцев:** доходы и расходы по месяцам, клик по месяцу открывает его.
- **CSV:** экспорт месяца для Excel и импорт обратно с проверкой каждой строки.
- **PWA:** установка на телефон и компьютер, работа без интернета.
- Тёмная и светлая тема, русский и английский языки, адаптивная вёрстка, работа с клавиатуры.

## Качество

| Проверка | Инструмент | Что покрыто |
| --- | --- | --- |
| Статический анализ | ESLint | весь код, включая service worker и тесты |
| Юнит-тесты — 71 | `node:test` | разбор и форматирование сумм, даты, статистика, бюджеты, CSV, пример данных |
| E2E-тесты — 32 | Playwright | операции, валидация, редактирование, бюджеты, график, экспорт и импорт, настройки, телефон, офлайн |
| CI | GitHub Actions | lint и юнит-тесты, затем E2E; отчёт Playwright сохраняется при падении |

E2E-тесты фиксируют дату через `page.clock`, поэтому дают одинаковый результат в любой день. Локаторы — атрибуты `data-testid`, общие действия вынесены в Page Object.

## Тестовая документация

В папке [`docs/`](docs/README.md): требования, тест-стратегия с анализом рисков, тест-дизайн (классы эквивалентности, граничные значения, таблица решений, переходы состояний), чек-листы, тест-кейсы, матрица покрытия и баг-репорты — от воспроизведения до исправления, как с BUG-05: сначала падающий тест, потом фикс.

## Как вносятся изменения

Ветка `main` защищена: прямые коммиты запрещены, изменения попадают в неё только через Pull Request, и слить его можно, только когда CI зелёный — lint, юнит-тесты и E2E. В каждом PR — [шаблон](.github/pull_request_template.md) с описанием, шагами проверки и чек-листом. Баги оформляются по [шаблону issue](.github/ISSUE_TEMPLATE/bug_report.md).

## Архитектура

Логика отделена от интерфейса: чистые модули ничего не знают о странице, поэтому проверяются юнит-тестами без браузера.

```
js/
├── money.js      суммы в тиынах, разбор ввода, форматирование через Intl
├── dates.js      даты ГГГГ-ММ-ДД без часовых поясов, названия месяцев
├── stats.js      итоги, категории, сравнение с прошлым месяцем, бюджеты, ряды для графика
├── csv.js        экспорт и импорт CSV с экранированием и проверкой строк
├── i18n.js       категории и тексты на двух языках
├── storage.js    безопасная работа с localStorage
├── demo.js       пример данных
├── ui/           отрисовка: кольцо, график, помощники DOM
└── main.js       состояние, события, связь логики со страницей
sw.js             service worker: офлайн-кэш
tests/unit/       юнит-тесты
tests/e2e/        E2E-тесты и Page Object
```

### Решения, о которых стоит знать

- **Суммы хранятся в тиынах** целыми числами: в JavaScript `0.1 + 0.2 !== 0.3`.
- **Даты — строки `ГГГГ-ММ-ДД`** в местном времени, без `Date` в UTC: операция не «переезжает» на соседний день.
- **Диаграммы на SVG вручную:** сектор кольца — окружность с `stroke-dasharray`, график рисуется под реальную ширину контейнера.
- **CSV для Excel:** разделитель `;` и BOM, иначе кириллица отображается неправильно.
- **Защита от XSS:** пользовательский текст выводится только через `textContent`.
- **Офлайн:** service worker использует стратегию «сначала сеть, затем кэш» — онлайн всегда свежая версия.

## Запуск

```bash
npm install
npm start            # http://localhost:4173
```

ES-модули и service worker не работают при открытии `index.html` двойным кликом (`file://`), поэтому нужен локальный сервер: `npm start` или расширение Live Server в VS Code.

```bash
npm run lint         # ESLint
npm run test:unit    # юнит-тесты
npx playwright install chromium   # один раз
npm run test:e2e     # E2E-тесты
npm test             # всё сразу
```
