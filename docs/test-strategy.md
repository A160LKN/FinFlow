# Тест-стратегия FinFlow

## Цель

Убедиться, что пользователь может безопасно вести учёт денег: суммы и итоги считаются точно, данные не теряются, ошибки ввода не попадают в учёт. Тестирование построено от рисков — больше всего проверок там, где ошибка стоит дороже всего.

## Анализ рисков

| Риск | Вероятность | Влияние | Как снижаем |
| --- | --- | --- | --- |
| Неверная сумма или итог (ошибки дробей, округление) | средняя | высокое | суммы в тиынах; юнит-тесты разбора и форматирования; E2E-проверка итогов |
| Потеря данных после перезагрузки или импорта | низкая | высокое | E2E на сохранение; импорт не заменяет, а дополняет данные; тест экспорт → импорт |
| Некорректная операция попадает в учёт (ноль, дата в будущем) | средняя | среднее | валидация суммы и даты; параметризованные E2E по классам ошибок |
| Выполнение вредоносного кода из комментария (XSS) | низкая | высокое | вывод только через `textContent`; E2E с HTML в комментарии |
| Импорт «битого» CSV ломает данные | средняя | среднее | построчная проверка; юнит-тесты на каждый вид ошибки |
| Ошибки на телефоне (вёрстка, касания) | средняя | среднее | E2E в мобильном профиле Pixel 7; ручной чек-лист |
| Ошибки дат на границах месяца и года | средняя | среднее | даты строками без часовых поясов; юнит-тесты на переходы через год |
| Приложение не открывается без интернета | низкая | низкое | E2E с отключённой сетью |

## Уровни тестирования

| Уровень | Что проверяем | Инструмент | Сейчас |
| --- | --- | --- | --- |
| Статический анализ | ошибки в коде до запуска | ESLint | весь код |
| Юнит | чистая логика: деньги, даты, статистика, бюджеты, CSV | `node:test` | 60 тестов |
| E2E | пользовательские сценарии в браузере | Playwright | 29 тестов: 28 на компьютере, 1 на телефоне |
| Ручное | то, что дорого или бессмысленно автоматизировать: внешний вид, удобство, установка PWA, реальные устройства | [чек-листы](checklists.md) | перед каждым релизом |

Логика проверяется юнит-тестами — они быстрые и точно указывают на причину. E2E покрывают сценарии целиком, но не дублируют все комбинации данных: граничные значения суммы, например, проверены юнит-тестами, а в E2E — по одному представителю каждого класса.

## Окружения

| Окружение | Назначение |
| --- | --- |
| Локально, `npm start` | разработка и отладка тестов |
| GitHub Actions, Ubuntu 24.04 + Chromium | автоматический прогон на каждое изменение |
| GitHub Pages | опубликованная версия для ручной проверки |
| Устройства для ручной проверки | Chrome и Safari на macOS, Safari на iPhone, Chrome на Android |

E2E-тесты фиксируют дату через `page.clock` (11 ноября 2026 года), часовой пояс Asia/Almaty и русскую локаль — результат не зависит от дня и места запуска.

## Тестовые данные

- Каждый E2E-тест начинает с пустого хранилища: тесты независимы и запускаются параллельно.
- Для аналитики используется кнопка «Заполнить примером»: 6 месяцев операций и 4 бюджета, построенные от зафиксированной даты.
- Для импорта — файл, выгруженный экспортом, и файл с намеренно испорченными строками.

## Критерии

**Начало тестирования:** сборка проходит ESLint, приложение открывается.

**Готовность к релизу:**
- все автотесты в CI зелёные;
- смоук-чек-лист пройден вручную на компьютере и телефоне;
- нет открытых дефектов с критичностью Critical и Major;
- известные дефекты Minor и Trivial описаны в [баг-репортах](bug-reports.md).

## Дефекты

| Критичность | Определение | Пример |
| --- | --- | --- |
| Critical | потеря данных или неверные деньги | итог месяца считается неправильно |
| Major | функция не работает, обходного пути нет | не удаётся сохранить изменения операции |
| Minor | функция работает с неудобством или ошибкой отображения | сумма показывается без второго знака тиынов |
| Trivial | косметика | подписи графика мелкие на телефоне |

Приоритет исправления определяется отдельно: косметический дефект на главном экране может быть важнее Minor в редко используемой функции.

## Что не тестируется

- Синхронизация между устройствами — её нет в продукте: данные хранятся в браузере.
- Нагрузочное тестирование — приложение работает без сервера.
- Браузеры старше двух последних версий.
