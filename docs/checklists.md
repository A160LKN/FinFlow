# Чек-листы

## Смоук — перед каждым релизом, 10 минут

Цель: убедиться, что основные функции работают и релиз можно тестировать дальше.

- [ ] Приложение открывается, нет ошибок в консоли браузера
- [ ] «Заполнить примером» загружает данные: итоги, диаграмма, бюджеты, график, список
- [ ] Добавляется расход и доход, итоги пересчитываются
- [ ] Ошибка при пустой сумме показывается и исчезает после исправления
- [ ] Операция редактируется и сохраняется
- [ ] Операция удаляется и возвращается
- [ ] Переход в прошлый месяц и обратно
- [ ] Экспорт CSV скачивает файл, он открывается в Excel с русскими буквами
- [ ] После перезагрузки данные на месте
- [ ] Переключение темы и языка

## Регресс — перед крупным релизом

**Операции**
- [ ] Все классы ошибок суммы из [тест-дизайна](test-design.md#1-сумма-операции--классы-эквивалентности-и-граничные-значения)
- [ ] Дата: сегодня принимается, завтра — нет
- [ ] Комментарий из 80 символов сохраняется полностью, 81-й ввести нельзя
- [ ] HTML в комментарии показывается текстом
- [ ] Смена типа меняет список категорий
- [ ] Операция за прошлый месяц открывает этот месяц
- [ ] Удаление операции во время её редактирования отменяет редактирование
- [ ] Уведомление об удалении исчезает через 5 секунд, после этого операцию вернуть нельзя

**Итоги и аналитика**
- [ ] Остаток отрицательный — показан с минусом и красным цветом
- [ ] Сравнение с прошлым месяцем: текущий месяц идёт / прошлый месяц открыт / нет расходов в прошлом месяце
- [ ] Клик по сектору и по легенде фильтрует список, «Показать все» снимает фильтр
- [ ] Бюджет: 79 %, 80 %, 100 %, больше 100 %
- [ ] Неверный лимит бюджета не сохраняется
- [ ] Клик по месяцу на графике открывает его

**Список**
- [ ] Группировка по дням, итог дня
- [ ] Фильтр «Расходы» и «Доходы», поиск без учёта регистра
- [ ] Три вида пустого списка: нет данных, пустой месяц, ничего не найдено

**Импорт и экспорт**
- [ ] Экспорт → очистка данных → импорт возвращает те же операции и итоги
- [ ] Импорт файла, выгруженного на английском
- [ ] Импорт файла с ошибками: сообщение с числом пропущенных строк

**Платформа**
- [ ] Четыре сочетания темы, языка и устройства из [попарной таблицы](test-design.md#7-окружение--попарное-тестирование)
- [ ] Две вкладки: изменения в одной появляются в другой

## Мобильная версия и браузеры

- [ ] Ширина 360 px — нет горизонтальной прокрутки
- [ ] Кнопки изменения и удаления операции видны без наведения
- [ ] Числовая клавиатура при вводе суммы
- [ ] Выбор даты системным календарём
- [ ] Safari на iPhone: форма, диаграмма, график, экспорт CSV
- [ ] Chrome на Android: то же
- [ ] Поворот экрана не ломает вёрстку

## PWA и офлайн

- [ ] В Chrome появляется кнопка «Установить», приложение устанавливается
- [ ] Установленное приложение открывается в отдельном окне с иконкой
- [ ] После первого открытия: режим «Офлайн» в DevTools → перезагрузка → приложение работает, данные на месте
- [ ] Операция, добавленная офлайн, сохраняется

## Доступность

- [ ] Все действия выполняются с клавиатуры: Tab, Enter, пробел, Escape
- [ ] Фокус виден на каждом элементе
- [ ] Легенда диаграммы и месяцы графика выбираются с клавиатуры
- [ ] Контраст текста достаточный в обеих темах (DevTools → Lighthouse → Accessibility)
- [ ] При включённом «Уменьшить движение» в системе анимации отключаются
